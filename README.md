# Ворота — локальная версия сайта

Статический сайт направления ворот, заборов и автоматики ООО «Концепция Строительства».

## Локальный запуск

Нужен Node.js 18 или новее. Запустить `npm run dev`, затем открыть `http://127.0.0.1:4173/`.

Локальная форма использует `POST /__preview/website-lead`. Сервер проверяет структуру заявки, возвращает отметку предпросмотра и не записывает, не журналирует и не пересылает значения. Для проверки не вводите настоящие персональные данные.

## Настройки до публичного запуска

- `https://vorota-vl.ru` указан в исходном задании как целевой домен на будущее; DNS, домен и production не менялись.
- Проверить разрешённый домен в CRM, обработчиков, фактический регион размещения данных и документы оператора.
- Фото ограничены 2 WebP-файлами до 800 КБ каждый и 1,5 МБ суммарно с учётом лимита API Gateway 2,5 МБ. Для их приёма CRM должна иметь `S4_PRIVATE_FILES_MODE=enabled`; UI CRM использует `VITE_S4_PRIVATE_FILES_MODE=enabled`.
- Указать утверждённый идентификатор Яндекс Метрики в `assets/site-config.js`. Счётчик запускается только после согласия на аналитику.
- Сверить опубликованные редакции политики и согласия с местами хранения данных и договорами обработчиков.

## Подтверждённость сведений

Публичные цены на ворота, заборы и автоматику, бренды приводов, статистика заказов и гарантийные сроки не подтверждены. Сайт не публикует придуманные цены, отзывы, бренды или гарантии. Указанный срок «от двух недель» является предварительным ориентиром и должен подтверждаться по каждому объекту.
